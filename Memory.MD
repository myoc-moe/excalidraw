# Project Memory

This file records durable project-level guidance for agents working in this repo.

## Instruction Sources

- Read `AGENTS.md` first.
- Read `MyocReadme.MD` before making changes in this fork.
- Do not use or create a top-level `codex.md` for this repo.

## Fork Policy Memory

Project memory for MyOC-specific fork behavior should be written into the `Fork UI Policy For Upstream Merges` section of `MyocReadme.MD`.

Changes described as "in our fork", "MyOC specific", or otherwise intentionally different from upstream Excalidraw behavior should include a focused regression test that locks in the fork behavior and guards against the upstream/original behavior returning.
